# Muestras: guitar-electric

Grabaciones del paquete [`tonejs-instrument-guitar-electric-mp3`](https://www.npmjs.com/package/tonejs-instrument-guitar-electric-mp3)
([tonejs-instruments](https://github.com/Makefully-Studios/tonejs-instruments)), licencia MIT.

Se usa una nota de cada pocos semitonos, en mono, recortada con un final suave y a 96 kbps.
Tone.js genera las notas intermedias a partir de las más cercanas.
