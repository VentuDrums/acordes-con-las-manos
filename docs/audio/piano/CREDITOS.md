# Muestras de piano

Grabaciones de piano del paquete [`tonejs-instrument-piano-mp3`](https://www.npmjs.com/package/tonejs-instrument-piano-mp3) 1.1.2
([tonejs-instruments](https://github.com/Makefully-Studios/tonejs-instruments)), licencia MIT.

Se usa una nota de cada tres semitonos (Do, Re♯, Fa♯, La) de las octavas 2 a 6, más el Do7, recortadas a 5 segundos
con un final suave y a 128 kbps. Tone.js genera las notas intermedias a partir de las más cercanas.
